# 在一份真实劳动力数据上的应用说明

这份说明记录本包在一份真实的岗位—任务数据上的应用:数据是什么、怎么处理的、得到了什么、结果对哪些选择不敏感。方法本身的细节在 `method.md`,逐条核对记录在 `validation.md`。

## 数据

数据来自一个制造业产业的招聘记录,覆盖 2016 年至 2026 年。每条记录包含招聘的岗位、岗位需要完成的任务,以及岗位所属的企业、行业和岗位类别。整理时,同一岗位在不同记录中出现的任务合并为该岗位的任务集合,得到"岗位—任务"对应表。

以 2016 年为例,整理后的规模是:6,147 个岗位、5,041 个任务、23,614 对"岗位—任务"对应,平均每个岗位约 3.8 个任务。其余年度按同一口径整理。数据受协议限制不随本仓库分发;本仓库提供结构相同的合成数据生成器和全部代码,下述每一步都可以在合成数据上复现。

## 处理口径

- 相似度:默认口径是 IDF 加权余弦,权值为 `w = log((N+1)/(df+1)) + 1`;同时保留不加权的 Ochiai 口径用于对照。两种口径的差别见下文"稳健性"。
- 过滤:PMFG,用块分解实现。与逐边整图检验的朴素实现在这份数据的 243,010 条候选边上逐条一致,均为 14,954 条边。
- 群落:Louvain,分辨率取 1,固定随机种子。孤立岗位自成一元群落,单独计数。
- 核心任务:群落内覆盖率排名前 20%,仅统计规模不少于 2 个岗位的群落。

## 2016 年的主要结果

| 指标 | 数值 |
|---|---|
| 过滤后网络 | 14,954 条边;245 个连通分量;3.8% 的岗位无任何相似岗位 |
| 群落 | 291 个;其中 60 个不少于 2 个岗位,47 个不少于 10 个岗位 |
| 模块度 | 0.943 |
| 最大群落 | 248 个岗位,占 4.0% |
| 群内 / 群间平均相似度 | 0.0407 / 0.0022,约 18.5 倍 |
| 块与桥 | 871 个块;80.3% 的岗位位于 5 节点以上的块;桥边占 3.5% |

几点解读。

群落是按任务内容组织的,不是企业或行业的影子。同一条边的两端属于同群落的比例是 96.7%,而随机打乱群落标签后这个比例只有 2.2%;属于同企业的比例是 11.7%(随机基线的 6.4 倍),同行业 20.8%(基线的 1.9 倍)。用划分与属性的一致性(NMI)衡量,岗位类别 0.602,企业 0.241,行业 0.085。也就是说,任务相近的岗位确实聚在一起,而这种相近跨企业、跨行业存在;每个群落中最大企业的发文份额不超过 10%,最大行业约占两成。

规模较大的群落都有明确的职业含义。典型的几个:研发群落(核心任务为实验设计、样品试制与测试记录),质量群落(来料与过程检验、不合格品处理),设备维护群落(巡检、点检、故障维修),行政人事销售群落(招聘、考勤、客户对接),生产调度群落(排产、物料跟催)。这些群落的划分没有用到任何职位名称,完全来自任务清单的相近程度。

连通和抱团是两回事。网络中有 519 条桥边(3.5%),它们连接的岗位只通过一条边挂在网络上,属于链式、间接的相近;真正成片的是 871 个块,八成岗位位于较大的块中。因此结论只对块和群落层面的结构负责,不把单条边的连通计为抱团。

围绕通用核心任务工作的岗位,任务暴露度更低。把每个岗位的核心任务占比(其任务中属于所在群落核心任务的比例)与该岗位的平均任务暴露度做相关,秩相关系数为 −0.302(p < 0.001)。方向是稳定的:任务越集中在本群落人人都有的通用任务上,岗位的暴露度越低;干专门任务、与群落内其他岗位重合少的岗位,暴露度更高。

## 稳健性

对结果影响最大的是相似度口径。这份数据的任务是 0/1 记录,不加权时 243,010 条候选边只有 372 个不同的相似度取值,全部处于并列组内;并列组内谁先谁后是任意的,但会改变被保留的边——随机换序后边集的重叠只有六成多(合成数据上为 0.63–0.69)。加权口径下相似度取值接近连续,并列几乎消失,换序后边集、群落划分和各项统计完全不变。因此正式结果采用加权口径,不加权口径仅作为对照保留,换序检查脚本随仓库提供。

其次,社区划分本身带随机性:同一张网络重复划分会得到不同结果。固定随机种子并规范边顺序后,重复运行结果完全一致。

算法层面,块分解实现与朴素实现逐边一致(204 组随机试验全部一致,真实数据上同样一致),最终网络通过独立的整图平面性检查。

## 后续

2017 年至 2026 年的年度结果按同一流程处理,随计算完成陆续加入;跨年的群落演化与暴露度变化将基于年度结果展开。
